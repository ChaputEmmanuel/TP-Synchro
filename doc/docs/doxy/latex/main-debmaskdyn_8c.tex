\doxysubsection{Description détaillée}
\+: Comment utiliser les options du bootloader pour modifier les masques de débogage. 

On n\textquotesingle{}utilise pas le registre ici, ce qui permet d\textquotesingle{}alléger sensiblement les choses.

Après les initialisations nécessaires, quelques messages de debogage sont affichés pour montrer l\textquotesingle{}impact des masques de debug.

On pourra par exemple passer en paramètre au bootloader

debug.\+masque.\+console=0x803

ou

debug.\+masque.\+console=0x003

Car 0x800 active les messages "{}a faire"{}. (C) Manu Chaput 2000-\/2025
