Le code source complet peut être téléchargé de la façon suivante \+: \begin{DoxyVerb} $ git clone git@github.com:ChaputEmmanuel/Manux.git
\end{DoxyVerb}
 il sera alors compilé \+: \begin{DoxyVerb} $ cd ManuX
 $ make CFG=printk
\end{DoxyVerb}
 puis on pourra le démarrer \+: \begin{DoxyVerb} $ make run
\end{DoxyVerb}
 Sous vos yeux ébahis apparaît alors une fenêtre ressemblant à ceci \+:



On peut également créer une image iso intégrant plusieurs noyaux différents puis lancer le tout \+: \begin{DoxyVerb} $ make multiso
 $ make runiso
\end{DoxyVerb}
 Mais c’est une autre histoire, on verra ça dans la section dédiée aux outils.\hypertarget{md_docs_2index_autotoc_md41}{}\doxysubsection{\texorpdfstring{Si ça marche, tant mieux, tu peux sauter une case}{Si ça marche, tant mieux, tu peux sauter une case}}\label{md_docs_2index_autotoc_md41}
