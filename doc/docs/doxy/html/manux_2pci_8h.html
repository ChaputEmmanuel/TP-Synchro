: Lecture d'un mot sur le registre de config du PCI

Les registres sont organisés comme décrits par exemple dans https://en.wikipedia.org/wiki/PCI_configuration_space#Standardized_registers

On a donc un offset qui nous dit quel long aller chercher puis éventuellement, via ses 2 bits de poids faible quel mot voire quel octet. Ce denier "niveau d'adressage" est fait par un masque (Et puisque les registres sont alignés sur 32 bits, on lit systématiquement un long à l'offset privé de ces deux bits)
