Description détaillée

Implantation de la console de type virtio.

A faire : la gestion de la mémoire n'est pas terrible ! J'alloue une page pour chaque nouveau message et je la supprime lorsque je récupère les buffers (voir les "WARNING Pas top" dans le code). Idéalement, il vaudrait mieux que ce soit virtio qui gère ça. Par exemple à l'initialisation, je lui dit que je veux qu'il copie les données. Du coup il alloue une première fois les buffers assiociés aux descripteurs, puis il les récupère avec les buffers, sans les libérer/réallouer. Au pire il peut les faire croitre si nécessaire !
