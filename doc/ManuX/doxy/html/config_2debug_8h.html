◆ MANUX_DEBUGMASK_VAR

#define MANUX_DEBUGMASK_VAR

Le débugage est-il paramétré à la compilation ou à l'exécution ?

Si cette macro est définie, le masque définissant les messages de débug affichés est stoqué dans une variable, sinon il est stoqué dans une macro.
