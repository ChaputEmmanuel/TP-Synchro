◆ bootloaderInitialiser()

void bootloaderInitialiser ( void  )

Lecture des informations fournies par le bootloader.

Cette fonction doit être invoquée relativement tôt, car elle a la charge de recopier des informations fournies par le bootloader. Ces informations étant dans une zone mémoire que l'on risque ensuite d'utiliser. Il s'agit de infoSysteme et cmdLine.
