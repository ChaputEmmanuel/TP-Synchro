ManuX-32

Bienvenue dans le monde merveilleux de ManuX !

Allons-y, let’s go, c’est parti les amis !

Le code source complet peut être téléchargé de la façon suivante : 

 $ git clone git@github.com:ChaputEmmanuel/Manux.git

il sera alors compilé : 

 $ cd ManuX
 $ make CFG=printk

puis on pourra le démarrer : 

 $ make run

Sous vos yeux ébahis apparaît alors une fenêtre ressemblant à ceci :

On peut également créer une image iso intégrant plusieurs noyaux différents puis lancer le tout : 

 $ make multiso
 $ make runiso

Mais c’est une autre histoire, on verra ça dans la section dédiée aux outils.

Si ça marche, tant mieux, tu peux sauter une case

La compilation et l’exécution du noyau nécessitent un certain nombre d’outils que je vais tenter de lister ici brièvement et sur lesquels je reviendrai dans la section [section:outils] dédiée aux outils.

Pour être bref, sur une distribution Linux moderne, l’installation des outils suivants devraient suffire : 

 # apt install gcc xorriso nasm qemu-system-i386 mtools pandoc

Ok, mais ensuite ?

Si vous avez réussi la première épreuve, vous avez donc un système sur lequel vous pouvez compiler et faire tourner ManuX . Félicitation et bienvenue dans mon monde …

Les différentes sections de ce document, forcément pas très à jour, vous permettront de comprendre comment cela fonctionne et d’y apporter vos modifications.

Bon courage !

Ou plutôt, comme dirait Gandalf “*Fuyez pauvres fous !*”

À partir de là, je suggère de parcourir la section présentant “la version courte”, dont l’objectif est de vous permettre de déterminer où aller chercher la suite des informations.
